### Bug fixes

- `node scripts/register-app.mjs` no longer creates the GitHub App when Wrangler couldn't store its secrets. GitHub hands out the private key and the webhook secret of a new app only once, and before, a Wrangler that wasn't signed in or a Worker that wasn't deployed yet left an app on GitHub whose key was lost, with only `wrangler secret put NAME failed` to go on. Now the script checks with `wrangler secret list` that Wrangler reaches the Worker before it sends the manifest to GitHub, and stops with what to do when it can't. Should a secret still fail to reach the Worker, it names the secrets that are stored and those that are missing, and the page of the app's settings where you make a new private key and set a new webhook secret, or delete the app and run the script again.
