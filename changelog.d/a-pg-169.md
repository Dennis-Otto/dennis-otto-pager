### Bug fixes

- A text to the bot that GitHub refuses now says so at once. Before, when GitHub was down, the GitHub App had lost its permission on the control repository or GitHub turned the dispatch down, the text got nothing at all: no 👀, no message and no 😢 an hour later either, so a lost text looked like a slow answer. Now it gets 😢 at once, and a message in its thread says what GitHub answered, so you can write it again once GitHub takes it. It needs no new permission and no new secret.
