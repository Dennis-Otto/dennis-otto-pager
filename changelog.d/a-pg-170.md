### Bug fixes

- A free text of more than 4000 characters, such as a pasted log, now gets an answer in its thread at once that says how long it is and what the control repository takes, and goes nowhere. Before, the pager sent it, the control repository refused it in a run that failed red, and the text showed 👀 for an hour and then 😢 without a reason. 🛠 Start fix now sends only the entries of its repository, each label cut to 300 characters, so a failed event of GitHub in the same alarm, or an alert with a long description, no longer makes the control repository refuse the whole fix and leave the thing in *fixing* for an hour.
