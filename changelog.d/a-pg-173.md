### Features

- The words below a photo, a file or a voice message now reach the control repository as a text does, with its 👀 and its answer: a screenshot sent into the topic of an issue with "is this the bug they mean?" is no longer dropped. Before, the pager read only the text of a message, which Telegram leaves empty for a photo or a file, so such a message got no reaction and no answer and looked like a dead pager. A photo, a file or a voice message without words now gets an answer in its thread at once, that the pager reads text only, and `/help` says so too. The picture, the file and the voice itself still stay in Telegram. It needs no new permission and no new secret.
