### Bug fixes

- A pull request of someone else from a fork now pages when it opens, also when its branch is named like one of release-please, such as `release-please--branches--main`, which a fork that runs release-please gets by itself and anyone can choose. Before, the pager took every such pull request for a release and stayed quiet: it came without a message and without a draft, its end didn't tick its thing off, and new commits on it brought no news. Now only a branch of release-please of the repository itself makes a release, and every other pull request is a contribution like any other. It needs no new permission and no new secret.
