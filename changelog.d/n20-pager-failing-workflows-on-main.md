### Features

- Any workflow that fails on `main` pages you once, not as a mail of GitHub per run: a push, a schedule, a bot such as *Findings* or *After the checks*, or a start by hand. Its message, such as *🔴 Docs fails on main in Dennis-Otto/player-switch-for-autodarts*, names the jobs that failed, each linked to its log, and offers 🔁 **Rerun** of the failed jobs and ✖ **Ignore**. Each run that fails again edits it in place, with how often and when, without a notification, and a run that passes the jobs that failed turns it ✅. A first attempt waits ten minutes for the rerun that *After the checks* makes of the tests and of a release, so a rerun that passes never pages. A required job of GitHub Actions now pages as its workflow, and an issue of the bot-health bot as the run that it names, so the same failure no longer pages twice. With this, you can turn off the mails of GitHub Actions in your notification settings. It needs no new permission and no new event of the app.
