# Dennis Otto Pager

A Telegram bot on a Cloudflare Worker that tells its maintainer only what needs them in their GitHub repositories, and acts on it with a button.

This is the start of the website of Dennis Otto Pager. MkDocs builds it from the pages in `docs/`, as `mkdocs.yml` says, and every change of `main` publishes it on GitHub Pages. Replace this page with the guide for the users, and give every further page its place in the menu, `nav` in `mkdocs.yml`. German pages sit next to their English ones, such as `index.de.md` beside `index.md`, as `mkdocs.yml` shows.
